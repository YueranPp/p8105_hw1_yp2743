``` r
data("penguins", package = "palmerpenguins")
```

Description of penguins dataset:

Dataset ‘penguins’ contain 344 observations with 8 variables, and each
row represents one penguin. Variables include species (`species`:
Adelie, Chinstrap, and Gentoo), island (`island`:Biscoe, Dream, and
Torgersen), bill depth (`bill_depth_mm`) and bill length
(`bill_length_mm`) in millimeters, sex (`sex`), body mass
(`body_mass_g`) in grams, and year (`year`).

The average flipper length among the studied penguin is 200.9152047mm.

# Scatterplot

Below is a scatterplot using bill length (x-axis) against flipper length
(y-axis), with points colored by species. Two observations with missing
measurements are omitted from the plot.

