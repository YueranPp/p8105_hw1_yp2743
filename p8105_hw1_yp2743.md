# Problem 2

## Create a data frame

- a random sample of size 10 from a standard Normal distribution

- a logical vector indicating whether elements of the sample are greater
  than 0

- a character vector of length 10

- a factor vector of length 10, with 3 different factor “levels”

``` r
hw1_df = tibble(
  sample = rnorm(10),
  logical_vec = sample > 0,
  char_vec = c("y","p", "2","7", "4", "3", "H", "W", "No.", "1"),
  factor_vec = factor(c("medium","grande","venti","medium","grande","venti","medium","grande","venti","medium"))
)
```

## Take the mean of a variable in a dataframe,

``` r
mean(pull(hw1_df, sample))
## [1] 0.1057237
mean(pull(hw1_df, logical_vec))
## [1] 0.5
mean(pull(hw1_df, char_vec))
## Warning in mean.default(pull(hw1_df, char_vec)): argument is not numeric or
## logical: returning NA
## [1] NA
mean(pull(hw1_df, factor_vec))
## Warning in mean.default(pull(hw1_df, factor_vec)): argument is not numeric or
## logical: returning NA
## [1] NA
```

From `sample`, which is a numeric variable, I got a valid mean.

From `logical_vec`, which is a logical vector generates TRUE or FALSE, I
got mean of 0.4.

From `char_vec`, which is a character vector, I got NA.

From `factor_vec`, which is a character vector, I got NA.

## Code chunk convertlogical, character, and factor variables to numeric.

``` r
as.numeric(pull(hw1_df, logical_vec))
as.numeric(pull(hw1_df, char_vec))
## Warning: NAs introduced by coercion
as.numeric(pull(hw1_df, factor_vec))
```

## What happens, and why?

For logical vector, numeric conversion leads to 0 and 1 result, which is
true or false. I also receive a warning from R that NAs introduced by
coercion.

For character vector, numeric conversion leads to NA and number result,
this makes sense because I treat my uni as characters, but four digits
are actually number.

For level vector, numeric conversion leads to 1, 2, and 3. `medium` is
level 1, `grande` is level 2, `venti` is level 3. This makes sense, R
treats it into three level that has an hierarchy.
